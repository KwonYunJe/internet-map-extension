Internet Map 개인정보 처리방침

최종 수정일: 2026년 10월 7일

1. 개요

Internet Map은 사용자의 웹사이트 이용 패턴을 시각적인 인터넷 지도로 보여주는 Chrome 확장 프로그램입니다.

Internet Map은 서비스 제공에 필요한 최소한의 브라우징 정보를 사용자의 기기에서 처리합니다.

2. 처리하는 정보

Internet Map은 다음 정보를 처리할 수 있습니다.

  • 방문한 웹사이트의 도메인 또는 URL
  • 웹사이트 방문 및 활성 시간
  • 웹사이트 방문 횟수
  • 웹사이트 간 이동 관계
  • 웹사이트 favicon 정보

3. 정보의 이용 목적

해당 정보는 다음 기능을 제공하기 위해서만 사용됩니다.

  • 사용자의 웹사이트 이용 통계 계산
  • 웹사이트별 이용 시간 표시
  • 웹사이트 간 이동 관계 시각화
  • Internet Map 그래프 및 이용 순위 생성

4. 정보의 저장

Internet Map이 생성하는 브라우징 기록과 통계 데이터는 사용자의 브라우저 내부 로컬 저장소에 저장됩니다.

해당 데이터는 Internet Map 개발자의 서버로 전송되지 않습니다.

5. 제3자 제공

Internet Map은 사용자의 브라우징 기록이나 기타 사용자 데이터를 제3자에게 판매, 공유 또는 제공하지 않습니다.

6. 광고 및 추적

Internet Map은 사용자 데이터를 광고, 사용자 프로파일링 또는 신용 평가 목적으로 사용하지 않습니다.

7. 데이터 삭제

사용자는 Internet Map의 데이터 삭제 기능을 사용하거나 확장 프로그램을 제거하여 저장된 데이터를 삭제할 수 있습니다.

8. Chrome Web Store Limited Use

Internet Map의 사용자 데이터 사용은 Chrome Web Store User Data Policy 및 Limited Use 요구사항을 준수합니다.

9. 개인정보 처리방침 변경

Internet Map의 데이터 처리 방식이 변경될 경우 본 개인정보 처리방침도 이에 맞게 수정됩니다.
